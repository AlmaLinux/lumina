This records a declared listing

Use this to catalog hardware that cannot run the certification suite yet: pre-release or embargoed parts, a machine you do not have shell access to, or a vendor's own test evidence. A declared listing is labeled as unproven and counts as a community confirmation once a reviewer accepts it. Certification comes from running the suite, which is also how a listing earns a vendor or AlmaLinux tier.
