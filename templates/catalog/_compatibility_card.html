Both pages answer the same two questions per AlmaLinux release - who certified it, and how many community members confirmed it - so the card chrome is one template. It had already drifted: software used Tabler's `card-table` and a real `card-footer` for its note, while hardware wrapped a `table-sm` in `card-body p-0` and put the note in a padded paragraph. Same information, visibly different spacing. The rows genuinely differ and stay per-catalog. Software rows carry an HTMX id and a confirm/withdraw control and can be awaiting review; hardware rows carry a minor floor in the release label and a proven-versus-declared distinction, and have no control because attesting there means running the suite. So the row template is passed in rather than shared. Adding `only` to the software include "for consistency" silently removes that control for every signed-in viewer, with no error and no failing template. {% endcomment %}
