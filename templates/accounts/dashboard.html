Run the certification suite

On the machine you want certified. The suite runs the tests and produces a result bundle.

{% include "core/_run_the_suite_command.html" %}

{% comment %}Both routes, because which one applies is a fact about the machine rather than a preference: a server with no route to this site cannot submit for itself.{% endcomment %}

Then get the result here, whichever suits the machine:

  • If the machine can reach this site, run alma-certify register on it and enter the code it shows on Authorize a machine. It submits its own results from then on.
  • If it cannot, produce a bundle with alma-certify bundle <run-id>, copy it off, and upload it here. It is processed exactly like an online submission.

Either way the run arrives as a draft, and this page will ask you for anything the catalog needs before a reviewer sees it. A run submitted with --scope is a claim about that component alone, so it is never asked for the host machine's details.
