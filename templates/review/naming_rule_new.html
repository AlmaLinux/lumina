Writing the pattern

It does two jobs: if it does not match, the rule does not apply, and if it does, its groups are what the name is built from. Case is ignored, so radeon finds Radeon.

Groups

Bracket the part you want to keep. Against cpu.model holding AMD Ryzen 7 PRO 7840U w/ Radeon 780M Graphics:

{% verbatim %}
PatternTemplateGives
w/ (Radeon \S+) {{ match.1 }} Radeon 780M
w/ (?P<igpu>Radeon \S+) {{ match.igpu }} Radeon 780M
(Radeon) (\S+) {{ match.2 }} by {{ match.1 }} 780M by Radeon
any {{ match.0 }} the whole matched text
{% endverbatim %}

Number them left to right by their opening bracket. (?:…) groups without capturing, for a choice you do not want to read back: w(?:/|ith) accepts both w/ and with, and is still no match.1.

Pieces
.any one character
\d \w \s a digit, a letter or digit, a space
\Sanything but a space, so: one word
* + ? none or more, one or more, none or one
*? +? the same, stopping as early as it can
[MK] [^MK] one of these, anything but these
a|beither
^ $the start, the end
\b a word boundary, so \bRX\b is not TRX
(?=x) (?!x) followed by, not followed by
